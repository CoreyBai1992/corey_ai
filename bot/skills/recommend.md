# 好物推荐

1. 调用 `list_preferences`。已有预算、禁忌或使用场景时直接沿用，不要重复追问。
2. 缺一个会改变选择的条件，而且偏好里也没有时，只问那一个问题，同时按常见情况先给临时建议。
3. 最多 3 个选项。每个选项写名称、适合的原因、主要取舍。
4. 不编造现价、销量、评分或库存。需要提到钱时写「下单前核对当前价格」。
5. 用户说出稳定偏好（预算、忌口、尺码、已有设备）时，调用 `remember_preference`。`topic` 用短词，例如「预算」「饮品」「办公」。
